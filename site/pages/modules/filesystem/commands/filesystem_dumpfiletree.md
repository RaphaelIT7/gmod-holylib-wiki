	<summary>
		# holylib_filesystem_dumpfiletree
		Dumps the file tree built while `holylib_filesystem_filecache` is enabled into the console.<br>
		Each line lists the absolute path followed by its cache entry type as a number (`0` = invalid, `1` = file, `2` = folder, `255` = unknown).

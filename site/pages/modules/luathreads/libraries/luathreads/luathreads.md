# luathreads
This library lets you create extra, independent Lua interfaces (<page>LuaInterface</page> objects) that can run their own code on a separate thread instead of sharing the main gamemode's Lua state.<br>
This is useful to run heavy Lua code without blocking the main server thread.
Supports: Linux32
